Hush — breadboard wiring (v1, XIAO ESP32-S3)

Diagram

Pin-to-pin wiring for the Hush prototype. Hub board is the Seeed Studio
XIAO ESP32-S3, which exposes ONLY 11 GPIOs (1..9, 43, 44). Canonical pin
assignments live in src/hw/pins.rs; this file mirrors them for assembly.
Regenerate the renders with `make regen` in this directory.

v1 layout: RFID + microSD share ONE SPI bus; the status LED is a single
WS2812 (one data pin); one multifunction button. The rotary encoder and a
second button are dropped in v1 (no free pins) — see PLAN.md.
